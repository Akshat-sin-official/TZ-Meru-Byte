# Source Notes

This pack was prepared by cross-checking:
- Official `Problem statement.pdf` (6 pages).
- `CrunchWeek_StarterPack/README.md`.
- `data/cit_public.json` public dataset schema and calendar.
- `validator.py` executable checks, soft scoring, booking priority and exam logic.
- `examples/sample_disruption.json`, `examples/schedule.example.json`, `examples/sample_requests.md`.
- `CIT_Feature_Guide.pdf` (teammate proposal, treated as non-authoritative).

The teammate guide's extras are included as recommended enhancements, not misrepresented as official requirements. This pack is an engineering baseline; the official source files and current validator must be inspected again whenever organisers provide an updated dataset, schema or validator.
